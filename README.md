# Mohammed Zain Ul Abdeen — Portfolio

A clean, responsive, publish-ready personal portfolio focused on AI/ML, research and software engineering.

## Files

- `index.html` — semantic page structure and portfolio content
- `style.css` — responsive visual system and layout
- `script.js` — mobile menu, scroll progress, reveal animation and copy-email interaction
- `assets/zain-official-pic.jpg` — supplied professional profile photo
- `favicon.svg` — site favicon

## Publish

### GitHub Pages
1. Create a GitHub repository (for example `zain-portfolio`).
2. Upload the files from this folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from branch → main → / (root)**.
5. Save and wait for GitHub Pages to publish.

### Vercel / Netlify
Upload the folder or connect the GitHub repository. No build command is required because this is a static HTML/CSS/JS site.

## Before publishing
